# Inventory Management Dictionary System

## Description
A Python project that manages product inventory using a dictionary. It allows users to add, search, update, and delete product records while tracking stock quantities through a command-line interface.

## Features
- Add product records
- Search products by name
- Update stock quantity
- Delete product records
- Display all inventory records

## Concepts Used
- Python Dictionary
- Loops
- Conditional Statements
- Dictionary Methods
- User Input

## How to Run
1. Run `inventory_management_dictionary.py`.
2. Enter product names and stock quantities.
3. Follow the on-screen instructions.

## Learning Outcome
This project demonstrates how to use Python dictionaries to store, manage, update, and retrieve inventory records while improving problem-solving and dictionary manipulation skills.
