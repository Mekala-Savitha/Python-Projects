# Student Marks Dictionary System

## Description
A Python project that manages student records using a dictionary. It allows users to add, search, update, delete, and analyze student marks through a command-line interface.

## Features
- Add student records
- Search student marks
- Update marks
- Delete student records
- Check student existence
- Display highest and lowest marks
- Calculate average marks
- Display students scoring above 75
- Sort students by name
- Sort students by marks

## Concepts Used
- Python Dictionary
- Loops
- Conditional Statements
- Dictionary Methods
- sorted() Function
- Lambda Function

## How to Run
1. Run `student_marks_dictionary.py`.
2. Enter student names and marks.
3. Follow the menu prompts displayed on the screen.

## Learning Outcome
This project demonstrates how to use Python dictionaries to manage and analyze student records efficiently.
