# Employee Department Dictionary System

## Description
A Python project that manages employee department records using a dictionary. It allows users to add, search, update, and delete employee department details through a command-line interface.

## Features
- Add employee records
- Search employee department by name
- Update employee department
- Delete employee records
- Display all employee department records

## Concepts Used
- Python Dictionary
- Loops
- Conditional Statements
- Dictionary Methods
- User Input

## How to Run
1. Run `employee_department_dictionary.py`.
2. Enter employee names and their departments.
3. Follow the on-screen instructions.

## Learning Outcome
This project demonstrates how to use Python dictionaries to store, manage, update, and retrieve employee department records while improving problem-solving and dictionary manipulation skills.
