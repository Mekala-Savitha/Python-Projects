# Phone Book Dictionary System

## Description
A Python project that manages phone book records using a dictionary. It allows users to add, search, update, and delete contact details through a command-line interface.

## Features
- Add contact records
- Search contacts by name
- Update phone numbers
- Delete contact records
- Display all phone book records

## Concepts Used
- Python Dictionary
- Loops
- Conditional Statements
- Dictionary Methods
- User Input

## How to Run
1. Run `phone_book_dictionary.py`.
2. Enter contact names and phone numbers.
3. Follow the on-screen instructions.

## Learning Outcome
This project demonstrates how to use Python dictionaries to store, manage, update, and retrieve phone book records while improving problem-solving and dictionary manipulation skills.
