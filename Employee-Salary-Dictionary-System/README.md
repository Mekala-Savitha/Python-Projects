# Employee Salary Dictionary System

## Description
A Python project that manages employee salary records using a dictionary. It allows users to add, search, update, delete, and analyze employee salary details through a command-line interface.

## Features
- Add employee records
- Search employee salary
- Update employee salary
- Delete employee records
- Check employee existence
- Display highest and lowest salary
- Calculate average salary
- Display employees with salary above a specified amount
- Sort employees by name
- Sort employees by salary

## Concepts Used
- Python Dictionary
- Loops
- Conditional Statements
- Dictionary Methods
- `sorted()` Function
- Lambda Function

## How to Run
1. Run `employee_salary_dictionary.py`.
2. Enter employee names and salaries.
3. Follow the on-screen instructions.

## Learning Outcome
This project demonstrates how to use Python dictionaries to store, manage, and analyze employee salary records while improving problem-solving and data management skills.
