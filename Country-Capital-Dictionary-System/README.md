# Country Capital Dictionary System

## Description
A Python project that manages country and capital records using a dictionary. It allows users to add, search, update, and delete country-capital records through a command-line interface.

## Features
- Add country and capital records
- Search capital by country name
- Update country capital
- Delete country records
- Display all country-capital records

## Concepts Used
- Python Dictionary
- Loops
- Conditional Statements
- Dictionary Methods
- User Input

## How to Run
1. Run `country_capital_dictionary.py`.
2. Enter country names and their capitals.
3. Follow the on-screen instructions.

## Learning Outcome
This project demonstrates how to use Python dictionaries to store, manage, update, and retrieve country-capital records while improving problem-solving and dictionary manipulation skills.
