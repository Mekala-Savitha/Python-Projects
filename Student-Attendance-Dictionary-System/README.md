# Student Attendance Dictionary System

## Description
A Python project that manages student attendance records using a dictionary. It allows users to add, search, update, and delete student attendance records through a command-line interface.

## Features
- Add student attendance records
- Search attendance by student name
- Update attendance status
- Delete student attendance records
- Display all attendance records

## Concepts Used
- Python Dictionary
- Loops
- Conditional Statements
- Dictionary Methods
- User Input

## How to Run
1. Run `student_attendance_dictionary.py`.
2. Enter student names and their attendance status (Present/Absent).
3. Follow the on-screen instructions.

## Learning Outcome
This project demonstrates how to use Python dictionaries to store, manage, update, and retrieve student attendance records while improving problem-solving and dictionary manipulation skills.
