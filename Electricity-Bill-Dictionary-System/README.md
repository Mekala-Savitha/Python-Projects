# Electricity Bill Dictionary System

## Description
A Python project that manages customer electricity bill records using a dictionary. It allows users to add, search, update, delete, and analyze electricity bill details through a command-line interface.

## Features
- Add customer records
- Search customer bill by name
- Update electricity bill amount
- Delete customer records
- Check if a customer exists
- Display the highest electricity bill
- Display the lowest electricity bill
- Calculate the total electricity bill amount
- Calculate the average electricity bill
- Display customers with bills of ₹1000 or more
- Display customers with bills below ₹500
- Sort customers by name
- Sort customers by bill amount

## Concepts Used
- Python Dictionary
- Loops
- Conditional Statements
- Dictionary Methods
- `max()` and `min()` Functions
- `sorted()` Function
- Lambda Function
- User Input

## How to Run
1. Run `electricity_bill_dictionary.py`.
2. Enter customer names and electricity bill amounts.
3. Follow the on-screen instructions.

## Learning Outcome
This project demonstrates how to use Python dictionaries to store, manage, update, and analyze electricity bill records while improving problem-solving and dictionary manipulation skills.
