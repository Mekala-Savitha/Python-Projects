# Quiz Score Dictionary System

## Description
A Python project that manages student quiz scores using a dictionary. It allows users to add, search, update, delete, and analyze quiz score records through a command-line interface.

## Features
- Add student quiz records
- Search quiz scores by student name
- Update quiz scores
- Delete student records
- Check if a student exists
- Display the highest quiz score
- Display the lowest quiz score
- Calculate the total quiz score
- Calculate the average quiz score
- Display students with scores of 80 or more
- Display students with scores below 40
- Sort students by name
- Sort students by quiz score

## Concepts Used
- Python Dictionary
- Loops
- Conditional Statements
- Dictionary Methods
- `max()` and `min()` Functions
- `sorted()` Function
- Lambda Function
- User Input

## How to Run
1. Run `quiz_score_dictionary.py`.
2. Enter student names and their quiz scores.
3. Follow the on-screen instructions.

## Learning Outcome
This project demonstrates how to use Python dictionaries to store, manage, update, and analyze quiz score records while improving problem-solving and dictionary manipulation skills.
