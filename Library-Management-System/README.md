# Library Management System

## Description
A Python project that manages library book records using nested dictionaries. It allows users to add, search, update, delete, and analyze book details through a command-line interface.

## Features
- Add book records
- Search books by Book ID
- Update book details
- Delete book records
- Check if a book exists
- Display the book with the highest number of copies
- Display the book with the lowest number of copies
- Calculate the average number of copies
- Display books with 10 or more copies
- Display books with less than 5 copies
- Sort books by Book ID
- Sort books by book name
- Sort books by number of copies

## Concepts Used
- Python Nested Dictionary
- Loops
- Conditional Statements
- Dictionary Methods
- `max()` and `min()` Functions
- `sorted()` Function
- Lambda Function
- User Input

## How to Run
1. Run `library_management_system.py`.
2. Enter book details such as Book ID, name, author, category, and number of copies.
3. Follow the on-screen instructions.

## Learning Outcome
This project demonstrates how to use nested dictionaries to store, manage, update, and analyze library book records while improving problem-solving, data organization, and dictionary manipulation skills.
