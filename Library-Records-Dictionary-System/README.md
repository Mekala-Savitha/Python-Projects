# Library Records Dictionary System

## Description
A Python project that manages library book records using a dictionary. It allows users to add, search, update, and delete book records through a command-line interface.

## Features
- Add book records
- Search books by name
- Update book author details
- Delete book records
- Display all library records

## Concepts Used
- Python Dictionary
- Loops
- Conditional Statements
- Dictionary Methods
- User Input

## How to Run
1. Run `library_records_dictionary.py`.
2. Enter book names and author names.
3. Follow the on-screen instructions.

## Learning Outcome
This project demonstrates how to use Python dictionaries to store, manage, update, and retrieve library book records while improving problem-solving and dictionary manipulation skills.
