# Cricket Scorecard Dictionary System

## Description
A Python project that manages cricket player scores using a dictionary. It allows users to add, search, update, delete, and analyze player records through a command-line interface.

## Features
- Add player records
- Search player scores
- Update player runs
- Delete player records
- Check if a player exists
- Display the highest and lowest scorer
- Calculate total team score
- Calculate average runs per player
- Display players who scored a half-century (50+ runs)
- Display players who scored a century (100+ runs)
- Display players who got out for zero (Duck)
- Sort players by name
- Sort players by runs

## Concepts Used
- Python Dictionary
- Loops
- Conditional Statements
- Dictionary Methods
- `max()` and `min()` Functions
- `sorted()` Function
- Lambda Function
- User Input

## How to Run
1. Run `cricket_scorecard_dictionary.py`.
2. Enter player names and their runs.
3. Follow the on-screen instructions.

## Learning Outcome
This project demonstrates how to use Python dictionaries to manage cricket scorecards, perform data analysis, sort records, and apply various dictionary operations while improving problem-solving skills.
