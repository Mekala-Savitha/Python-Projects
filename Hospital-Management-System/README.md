# Hospital Management System

## Description
A Python project that manages hospital patient records using nested dictionaries. It allows users to add, search, update, delete, and analyze patient details through a command-line interface.

## Features
- Add patient records
- Search patients by Patient ID
- Update patient details
- Delete patient records
- Check if a patient exists
- Display the patient with the highest bill amount
- Display the patient with the lowest bill amount
- Calculate the average bill amount
- Display patients with a bill of ₹50,000 or more
- Display patients with a bill below ₹10,000
- Sort patients by Patient ID
- Sort patients by patient name
- Sort patients by bill amount

## Concepts Used
- Python Nested Dictionary
- Loops
- Conditional Statements
- Dictionary Methods
- `max()` and `min()` Functions
- `sorted()` Function
- Lambda Function
- User Input

## How to Run
1. Run `hospital_management_system.py`.
2. Enter patient details such as Patient ID, name, age, disease, doctor, and bill amount.
3. Follow the on-screen instructions.

## Learning Outcome
This project demonstrates how to use nested dictionaries to store, manage, update, and analyze hospital patient records while improving problem-solving, data organization, and dictionary manipulation skills.
