# Student Management System

## Description
A Python project that manages student records using nested dictionaries. It allows users to add, search, update, delete, and analyze student details through a command-line interface.

## Features
- Add student records
- Search students by Student ID
- Update student details
- Delete student records
- Check if a student exists
- Display the student with the highest marks
- Display the student with the lowest marks
- Calculate the average marks
- Display students who scored 75 or more
- Display students who scored below 40
- Sort students by Student ID
- Sort students by name
- Sort students by marks

## Concepts Used
- Python Nested Dictionary
- Loops
- Conditional Statements
- Dictionary Methods
- `max()` and `min()` Functions
- `sorted()` Function
- Lambda Function
- User Input

## How to Run
1. Run `student_management_system.py`.
2. Enter student details such as ID, name, age, course, and marks.
3. Follow the on-screen instructions.

## Learning Outcome
This project demonstrates how to use nested dictionaries to store, manage, update, and analyze student records while improving problem-solving, data organization, and dictionary manipulation skills.
