# Product Price Dictionary System

## Description
A Python project that manages product prices using a dictionary. It allows users to add, search, update, and delete product records through a command-line interface.

## Features
- Add product records
- Search product by name
- Update product price
- Delete product records
- Display all product details

## Concepts Used
- Python Dictionary
- Loops
- Conditional Statements
- Dictionary Methods
- User Input

## How to Run
1. Run `product_price_dictionary.py`.
2. Enter product names and prices.
3. Follow the on-screen instructions.

## Learning Outcome
This project demonstrates how to use Python dictionaries to store, manage, update, and retrieve product price records while improving problem-solving and dictionary manipulation skills.
