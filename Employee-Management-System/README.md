# Employee Management System

## Description
A Python project that manages employee records using nested dictionaries. It allows users to add, search, update, delete, and analyze employee details through a command-line interface.

## Features
- Add employee records
- Search employees by Employee ID
- Update employee details
- Delete employee records
- Check if an employee exists
- Display the employee with the highest salary
- Display the employee with the lowest salary
- Calculate the average salary
- Display employees with a salary of ₹50,000 or more
- Display employees with a salary below ₹30,000
- Sort employees by Employee ID
- Sort employees by name
- Sort employees by salary

## Concepts Used
- Python Nested Dictionary
- Loops
- Conditional Statements
- Dictionary Methods
- `max()` and `min()` Functions
- `sorted()` Function
- Lambda Function
- User Input

## How to Run
1. Run `employee_management_system.py`.
2. Enter employee details such as ID, name, age, department, and salary.
3. Follow the on-screen instructions.

## Learning Outcome
This project demonstrates how to use nested dictionaries to store, manage, update, and analyze employee records while improving problem-solving, data organization, and dictionary manipulation skills.
