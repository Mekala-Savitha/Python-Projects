# Shopping Cart Dictionary System

## Description
A Python project that manages shopping cart records using a dictionary. It allows users to add, search, update, delete, and analyze product details through a command-line interface.

## Features
- Add product records
- Search products by name
- Update product prices
- Delete product records
- Check if a product exists
- Display the most expensive product
- Display the cheapest product
- Calculate the total cost of all products
- Calculate the average product price
- Display products costing ₹1000 or more
- Display products costing less than ₹500
- Sort products by name
- Sort products by price

## Concepts Used
- Python Dictionary
- Loops
- Conditional Statements
- Dictionary Methods
- `max()` and `min()` Functions
- `sorted()` Function
- Lambda Function
- User Input

## How to Run
1. Run `shopping_cart_dictionary.py`.
2. Enter product names and their prices.
3. Follow the on-screen instructions.

## Learning Outcome
This project demonstrates how to use Python dictionaries to store, manage, update, and analyze shopping cart records while improving problem-solving and dictionary manipulation skills.
