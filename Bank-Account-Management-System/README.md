# Bank Account Management System

## Description
A Python project that manages bank account records using nested dictionaries. It allows users to add, search, update, delete, and analyze account details through a command-line interface.

## Features
- Add bank account records
- Search accounts by Account Number
- Update account details
- Delete account records
- Check if an account exists
- Display the account with the highest balance
- Display the account with the lowest balance
- Calculate the average account balance
- Display accounts with a balance of ₹1,00,000 or more
- Display accounts with a balance below ₹10,000
- Sort accounts by Account Number
- Sort accounts by Account Holder Name
- Sort accounts by account balance

## Concepts Used
- Python Nested Dictionary
- Loops
- Conditional Statements
- Dictionary Methods
- `max()` and `min()` Functions
- `sorted()` Function
- Lambda Function
- User Input

## How to Run
1. Run `bank_account_management_system.py`.
2. Enter account details such as Account Number, Account Holder Name, Age, Account Type, Branch, and Balance.
3. Follow the on-screen instructions.

## Learning Outcome
This project demonstrates how to use nested dictionaries to store, manage, update, and analyze bank account records while improving problem-solving, data organization, and dictionary manipulation skills.
