# Movie Ratings Dictionary System

## Description
A Python project that manages movie ratings using a dictionary. It allows users to add, search, update, delete, and analyze movie ratings through a command-line interface.

## Features
- Add movie records
- Search movie ratings by name
- Update movie ratings
- Delete movie records
- Check if a movie exists
- Display the highest-rated movie
- Display the lowest-rated movie
- Calculate the average movie rating
- Display movies with ratings of 8 or above
- Display movies with ratings below 5
- Sort movies by name
- Sort movies by rating

## Concepts Used
- Python Dictionary
- Loops
- Conditional Statements
- Dictionary Methods
- `max()` and `min()` Functions
- `sorted()` Function
- Lambda Function
- User Input

## How to Run
1. Run `movie_ratings_dictionary.py`.
2. Enter movie names and their ratings.
3. Follow the on-screen instructions.

## Learning Outcome
This project demonstrates how to use Python dictionaries to store, manage, update, and analyze movie ratings while improving problem-solving and dictionary manipulation skills.
