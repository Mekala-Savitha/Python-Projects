# Voting System Dictionary

## Description
A Python project that manages candidate vote records using a dictionary. It allows users to add, search, update, delete, and analyze candidate vote details through a command-line interface.

## Features
- Add candidate records
- Search candidates by name
- Update candidate vote count
- Delete candidate records
- Check if a candidate exists
- Display the candidate with the highest votes (Winner)
- Display the candidate with the lowest votes
- Calculate the total number of votes
- Calculate the average number of votes per candidate
- Display candidates with 100 or more votes
- Display candidates with less than 50 votes
- Sort candidates by name
- Sort candidates by vote count

## Concepts Used
- Python Dictionary
- Loops
- Conditional Statements
- Dictionary Methods
- `max()` and `min()` Functions
- `sorted()` Function
- Lambda Function
- User Input

## How to Run
1. Run `voting_system_dictionary.py`.
2. Enter candidate names and the number of votes received.
3. Follow the on-screen instructions.

## Learning Outcome
This project demonstrates how to use Python dictionaries to store, manage, update, and analyze voting records while improving problem-solving and dictionary manipulation skills.
