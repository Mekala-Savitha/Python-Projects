# Course Registration Dictionary System

## Description
A Python project that manages course registration records using a dictionary. It allows users to add, search, update, delete, and analyze course enrollment details through a command-line interface.

## Features
- Add course records
- Search courses by name
- Update course enrollment
- Delete course records
- Check if a course exists
- Display the course with the highest enrollment
- Display the course with the lowest enrollment
- Calculate the total number of enrolled students
- Calculate the average number of students per course
- Display courses with 50 or more enrolled students
- Display courses with less than 20 enrolled students
- Sort courses by name
- Sort courses by enrollment

## Concepts Used
- Python Dictionary
- Loops
- Conditional Statements
- Dictionary Methods
- `max()` and `min()` Functions
- `sorted()` Function
- Lambda Function
- User Input

## How to Run
1. Run `course_registration_dictionary.py`.
2. Enter course names and the number of enrolled students.
3. Follow the on-screen instructions.

## Learning Outcome
This project demonstrates how to use Python dictionaries to store, manage, update, and analyze course registration records while improving problem-solving and dictionary manipulation skills.
